# Handoffs to risks

Plans for changes that must be made in `risks`. risks-web never makes them itself. Name files `NNN-<topic>.md`.

## Template

    # NNN: <title>

    ## Why
    What risks-web needs and why a workaround in this repo is not enough.

    ## Files in risks
    Exact paths.

    ## Change
    What to change.

    ## How risks-web will check it
    Acceptance check (test or command) run after the submodule pointer is bumped.
