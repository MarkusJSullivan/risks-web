# DPIA Risk Tabletop (web)

Static website for the DPIA Risk Tabletop game, served by GitHub Pages straight from this repo. The Python rules run in
the browser via [Pyodide](https://pyodide.org). Game source: [dpia-tabletop](https://github.com/MarkusJSullivan/dpia-tabletop).

Files: `index.html`, `boot.js`, `bridge.py`, `dpia_tabletop.zip` (cards and rules, no server code).

Code is MIT (`LICENSE`), card data CC BY 4.0 (`LICENSE-CONTENT`), based on the SDM (see attribution on the page).
